# Análise de Dados de Vendas com Python

## 📌 Objetivo
Realizar análise exploratória de dados de vendas utilizando Python,
com foco em indicadores e apoio à tomada de decisão.

## 🛠️ Ferramentas Utilizadas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Git e GitHub

## 🔍 Análises Realizadas
- Faturamento total
- Faturamento por produto
- Ticket médio
- Análise temporal de vendas
- Identificação de padrões

## 📈 Resultados
A análise permitiu identificar tendências de vendas e produtos com
maior impacto no faturamento.

## 📁 Estrutura do Projeto
- dados/: base de dados utilizada
- notebooks/: análise em Python
